Ejercicios y material del módulo de **Backend Avanzado con Node.js** del Bootcamp de Desarrollo Web FullStack de [KeepCoding](https://keepcoding.io/), centrado en TypeScript, arquitectura modular, testing E2E y servicios externos.

> 📌 La práctica final de este módulo está en un repositorio aparte: [bookshop-practice](https://github.com/Aratea10/bookshop-practice).

---

## 📚 Contenido del módulo

1. Migración de JavaScript a TypeScript
2. Arquitectura modular organizada por funcionalidad
3. Autenticación con JWT y bcrypt
4. Validación de datos con Zod
5. Monitorización de errores con Sentry
6. Envío de emails con Mailtrap
7. Tareas programadas con node-cron
8. Testing E2E con Jest + Supertest
9. Contenedorización con Docker

---

## 🔧 Tecnologías utilizadas

- **Node.js 22** + **TypeScript**
- **Express** — Framework web
- **MongoDB** + **Mongoose** — Base de datos y ODM
- **JWT** + **bcryptjs** — Autenticación
- **Zod** — Validación de esquemas
- **Sentry** — Monitorización de errores
- **Mailtrap** — Envío de emails
- **node-cron** — Tareas programadas
- **Jest + Supertest** — Testing E2E
- **Docker** — Contenedorización
